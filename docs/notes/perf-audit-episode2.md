# Episode2 全链路时间审计报告（2026-09-01）

> 数据来源：4 个已完成镜头的 stream.jsonl 时间戳逐事件分析（不含 007 运行中）
> 结论：单镜头 12-19 分钟，其中约 40% 是可压缩的流程开销

## 一、实测耗时结构（单镜头均值 ≈15 分钟）

| 环节 | 实测耗时 | 占比 | 说明 |
|---|---|---|---|
| 读技能+契约 | 1.7-3.1 min | ~15% | Read 18-23 次 + Skill 加载 3-6 次 |
| 写代码（含思考） | 6.5-11.2 min | ~50% | Write/Edit 3-8 次，每次间隔 10-60s（模型推理+长命令） |
| check+抽帧+渲染 bash | 3.2-8.7 min | ~30% | check/lint 跑 7 次、snapshot 3 次、render 2 次 |
| 模型大段空闲 | 每次 1 次 ×1-4 min | ~10% | 最长单次 231s（npm install 等待） |

## 二、慢的五个根因（按可优化空间排序）

1. **上下文装载靠现场翻文件**（省 1-2 min/镜头）
   - Claude 每镜头要 Read 18-23 次：frame.md(18KB)、scene-timing、transcription、hyperframes core/cli/motion、disney 规则、特效技能……
   - 每次读取 = 一次模型往返 = 5-15s 推理间隔
   - .claude 目录 44MB，但真正每个镜头都用的契约只有 ~2KB 关键信息

2. **check→修复→再check 循环无上限**（省 1-3 min/镜头）
   - npm run check 单镜头跑了 7 次；每次 check 本身 20-40s（headless 浏览器启动）
   - 质量门要求"所有 error 修复"，模型会循环修到满分，但很多 warning 可直接放行

3. **npm 首次安装在大段等待里**（已用共享依赖解决大半）
   - scene-002 出现过 231s 单次等待 = npm install
   - setup-shared-deps.py 已建好但本集未启用（执行器没接线）——下一集必接

4. **并发 2 + 串行排队**（结构性，受额度约束）
   - 7 镜头 ÷ 2 = 4 轮；总时长 = 4 × 单镜头时长
   - 并发 3 可省 1/3 墙钟时间，但额度消耗同步+50%

5. **模型单次推理慢**（底层约束）
   - 51 次间隔中 27 次 10-60s = 模型 token 生成速度
   - 只能靠换更快的执行模型解决，属于用户决策项

## 三、优化方案（预期单镜头 15min → 7-9min）

| # | 措施 | 节省 | 实施位置 |
|---|---|---|---|
| 1 | **预裁剪契约包**：执行器在拆镜后自动生成 scene-context.md（frame.md 关键 tokens + 本镜头词级时间 + 必守规则 10 条，≤2KB），prompt 直接要求"读 scene-context.md 即可开工，无需浏览其他技能文档"，仅特效命中时才读对应技能 | 1.5-2 min | run-scenes-v3.sh 新增步骤 |
| 2 | **check 预算制**：npm run check 最多 3 轮，error 清零即可渲染，warning 列入"已知警告"清单随镜头交付 | 1-3 min | 质量门文本修改 |
| 3 | **共享依赖接线**：拆镜后自动跑 setup-shared-deps.py，node_modules 符号链接到各镜头 | 1-4 min（首镜头 4min，后续≈0） | run-scenes-v3.sh 新增步骤 |
| 4 | **snapshot 一次成 3 帧**：`snapshot --at 0.5,中点,结尾` 一条命令代替 3 次 | ~1 min | 质量门文本修改 |
| 5 | **执行模型提速**（用户决策项）：执行层换响应更快的模型 | 视模型 | 用户改配置 |

## 四、不改的部分（质量红线）

- 质量门 7 条清单、终帧收束检查、独立视觉复核：这是"丑片拦截器"，Episode1 的教训不能丢
- 先试产一镜再批量：标准校准环节
- 25 分钟硬超时 + 熔断：额度保护

## 五、预期效果

- 单镜头：15 min → 7-9 min
- 全片（7 镜头，并发 2）：~55 min → **~30 min**
- 若并发恢复 3：~30 min → **~20 min**（额度+50%）
- 加上 TTS/拆镜/混音等固定环节，一条 1 分钟成片端到端：~70 min → **~45 min**（并发3：~35 min）
